# Sistemsko-programiranje-3



Zadatak 27:

Koristeći Rx.NET i Project Gutenberg (Gutendex) API, prikupiti opise knjiga (summaries) za zadatog autora. Rx vrši osnovno mapiranje dobijenih podataka i emituje ih kao poruke aktorima. Aktori čuvaju opise knjiga kao interno stanje i implementiraju Sentiment analizu koristeći ML.NET biblioteku. Sentiment računati na nivou pojedinačnog opisa knjige. Web server prima zahteve sa imenom autora i prevodi ih u poruke aktorima. Prikazati dobijene rezultate. 



Dokumentacija dostupna na linku: https://gutendex.com/
